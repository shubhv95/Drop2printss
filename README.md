# Drop2Print Website

This is a flat, GitHub Pages-ready static website made with HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Extract this ZIP.
3. Upload **the files inside** directly to the repository root. Do not upload a containing folder.
4. Commit the files.
5. Open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
7. Wait for the deployment to finish and open the URL shown on the Pages settings screen.

`index.html` must be at the repository root. This website does not require React, npm, or a build step.
