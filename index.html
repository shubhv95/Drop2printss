Easy Setup

How to Install the Extension in Chrome

The page itself works as a website. To install an extension, you need a separately packaged extension folder.

1

Get the extension folder

Download the actual Drop2Print extension package from its publisher and extract it to a folder.

2

Open extensions

In desktop Chrome, open a new tab and visit chrome://extensions.

3

Enable Developer mode

Turn on Developer mode from the extensions page. This option is available in desktop browsers.

4

Load unpacked

Select the extracted extension folder using “Load unpacked”. The website file alone is not an extension package.
